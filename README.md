# ljfxznode-script
An **Xboard-only** node server install script for [ljfxznode](https://github.com/csdfsdffese/ljfxznode) (Xray core only).

一个 **仅支持 Xboard** 面板的节点服务端安装脚本（仅 Xray 内核），支持 Vmess、Vless、Trojan、Shadowsocks 协议。

Find the source code here: [csdfsdffese/ljfxznode](https://github.com/csdfsdffese/ljfxznode)

如对脚本不放心，可使用此沙箱先测一遍再使用：https://killercoda.com/playgrounds/scenario/ubuntu

# 详细使用教程

[教程](https://github.com/csdfsdffese/ljfxznode)

# 一键安装

```
wget -N https://raw.githubusercontent.com/csdfsdffese/ljfxznode-script/master/install.sh && bash install.sh
```
